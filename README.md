# Westworth Is Watching

A volunteer-run website by Westworth Village residents who read the agendas, file the records requests, and show up to the meetings.

**Live site:** https://westworthiswatching.com

## What's here

- `index.html` — the home page (timeline, documents list, yard-sign request form)
- `topics/` — one page per topic (Our Village, Trinity Terrace, the election, lawsuits, P&Z, Pastry Gate)
- `meetings/` — one page per council or P&Z meeting, newest first, listed automatically
- `EDITING.md` — **start here if you want to help.** How to edit pages, add meetings, and upload documents from your browser, with the fact/speculation labeling rule explained.

## House rule

Everything on the site is labeled. Facts carry sources. Opinions and speculation say so, plainly. If a record proves us wrong, the record goes up and the page gets fixed.
